03 / GET STARTED

A little code.
A lot of possibilities.

Compose Pill works with your existing navigation and design system. Start with the dependency, then make it yours.

01 / INSTALLbuild.gradle.kts
// In commonMain, with mavenCentral()
implementation("io.github.samuolis:pill:0.1.0")
02 / CREATEKotlin
PillNavigationBar(
    items = destinations,
    selectedKey = currentRoute,
    onSelect = { route -> navigate(route) },
    scrubEnabled = true,
)
