# Compose Pill 0.3.0

- Choose `PillItemLayout.Vertical` for an icon above its label or `PillItemLayout.Horizontal` for an icon beside it.
- The indicator follows the finger and settles from its last drag position. Scrubbing gives one haptic tick as it crosses into another enabled destination. Pass `scrubHapticFeedback = null` to disable feedback.
- The icon callback receives visual activation as the indicator moves. Continue using `selectedKey` and `onSelect` as the source of truth for navigation.
- Overflowing bars bring the selected destination into view. Reordering preserves the identity of remembered icon and badge content.
- Custom bars can reuse the measured drag state, scrub modifier, coverage calculation, and item layout without adopting the built-in bar.
