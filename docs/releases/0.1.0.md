# Compose Pill 0.1.0

The first release provides a floating navigation bar for Compose Multiplatform on Android, iOS, desktop JVM and Compose Wasm.

- A controlled destination API with animated selection, optional drag-to-select, scroll minimization, badges and an adjacent action.
- Solid, frosted and custom glass surfaces, a shared backdrop, progressive blur and an optional safe-area placement host.
- Desktop, iOS and Wasm examples and a separate consumer fixture.

Add `implementation("io.github.samuolis:pill:0.1.0")` to a Compose Multiplatform source set and resolve it from Maven Central. See the [usage guide](https://github.com/samuolis/compose-pill/blob/v0.1.0/docs/usage.md) for placement and accessibility guidance.

Glass is a custom Haze effect, not the native Apple Liquid Glass API. Applications must apply reduced-motion and reduced-transparency preferences themselves, and should validate device performance, keyboard handling and insets for their layouts.
